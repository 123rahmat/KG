Agentic roles

Specialists are recruited by the situation, not switched on by default.

Kindgleam has a role catalog for strategy, evidence, analysis, architecture, implementation, critique, communication, diagnosis, debugging, testing, security, and performance. The runtime chooses the smallest useful team and can stay with one executor when that is enough.

CORE CONTROL Three logical roles shape a turn. The Step Manager and Resource & Data Manager are advisory. The Main Executor produces the user-facing work. The server remains authoritative.
